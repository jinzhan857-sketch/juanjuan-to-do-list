# 输入框空闲留白微调

PR #134合入后，展要求在键盘未打开时缩短输入框下方留白，并将初稿20像素调整为15像素，同时授权复查后合入。

基于main aa62d40db08173ec1d346c202238ce2fbe257997，仅将空闲输入框向下移15像素，bottom从96改为81；消息底部静态与动态留白同步缩短15像素，保证最后消息仍可滚到输入框上方。键盘打开时仍沿用原bottom 10像素，导航和键盘判断不变，不新增兼容处理。

实际独立合成来源390×844窗口，输入框底部759、导航顶部780，间距约21像素，较此前36像素减少15。最后消息底部682.94、输入框顶部703.67，末尾可完整查看；上弹菜单、选择和Esc关闭正常。见[截图](idle-gap.jpg)及[尺寸](idle-gap.json)。这不是实机软键盘验收，手机专项#135保持未完成，#110、#117继续保留。

32项键盘、导航及助手专项通过，最终1501项检查通过；最终提交归档及云端结果见本次PR交接。没有真实模型调用，累计仍630次。不发布、不迁移真实资料。本项是#135之前的已授权小修，不替代其手机矩阵，也不阻塞#119在独立分支推进。
