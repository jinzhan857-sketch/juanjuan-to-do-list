# 助手消息框一致性调整

展要求助手消息统一使用较宽的外框，确认创建后也不因文字变短而缩窄；时间放到语句框外下方。展随后用截图明确：只删除文字框内顶部“小猫＋卷卷”的标题行，保留左侧聊天头像和页面顶部品牌名称。

原因是原助手气泡按文字内容自然收缩，保存前后的回复文字不同。现保留左侧27像素头像和7像素间距，右侧气泡统一占满剩余消息区域并保持16像素圆角；时间独立放在气泡外下方。用户气泡仍靠右随内容适当收窄，时间同样位于框外。创建、编辑、确认、撤销、候选版本和已有记录格式未改，不迁移数据。

在接通真实AI的4271隔离页面，实际发送创建“整理公开资料”的合成日程，确认创建，再发送一句感谢并得到短回复。恢复左侧头像后，又实际创建并确认“核对公开目录”，复测最终布局。本次额外模型调用合计3次，继续计入原专项账本，不新增或清零额度。

390×844窗口中，最终待确认、已创建和简短回复外框宽度均304.67像素，左侧均52像素，圆角均16像素。每条助手回复左侧保留一个头像，框内角色标题为零，时间均位于框外下方。四主题逐一操作并核对相同结果，见[最终截图](message-layout.jpg)与[最终测量](message-layout.json)。桌面与原确认流程保持，手机实机仍由#135独立验收。
