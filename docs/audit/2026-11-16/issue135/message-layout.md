# 助手消息框一致性调整

展要求助手消息统一使用较宽的外框，确认创建后也不因文字变短而缩窄；时间放到语句框外下方，并删除消息中的卷卷标题、小猫标记及左侧头像，保留页面顶部品牌名称。

原因是原助手气泡按文字内容自然收缩，保存前后的回复文字不同；消息还以头像占位，并把角色标题和时间包在气泡内。现统一助手气泡占满消息区域并保持16像素圆角，用户气泡仍靠右随内容适当收窄；双方时间均放在各自气泡外下方。创建、编辑、确认、撤销、候选版本和已有记录格式未改，不迁移数据。

在接通真实AI的4271隔离页面，实际发送创建“整理公开资料”的合成日程，确认创建，再发送一句感谢并得到短回复。本次额外模型调用2次，继续计入原专项账本，不新增或清零额度。

390×844窗口中，待确认、已创建和简短回复外框宽度均338.67像素，左侧均18像素，圆角均16像素。时间均位于框外下方，消息内头像和角色标题数量为零。四主题逐一操作、查看截图并核对相同结果，见[截图](message-layout.jpg)与[测量](message-layout.json)。桌面与原确认流程保持，手机实机仍由#135独立验收。
