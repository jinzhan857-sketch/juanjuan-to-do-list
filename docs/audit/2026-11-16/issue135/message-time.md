# 聊天气泡与时间显示复查

展要求短回复按内容收窄，卷卷时间在框外左下，用户时间在框外右下，并减少相邻时间重复。保留左侧聊天头像，消息内部不恢复猫图标和卷卷标题。创建、修改等结构化卡片继续保持统一宽度，确认后也不缩窄。

## 实现与边界

普通气泡使用内容宽度和可用区域上限，含结构化详情的气泡保持整列宽度。时间从上一次实际显示的分钟计算，16:40显示、16:41隐藏、16:42显示；两个发言方共用一条时间线。跨本地日历日期强制显示，新聊天重新开始。仅改变渲染，不修改消息时间、存储、确认或撤销流程。

参考本机Impeccable、Apple Design和Apple Design HIG中的克制、对齐与内容优先原则，沿用现有主题、圆角和头像。两分钟规则来自展的要求，不是平台规范。没有添加依赖、动画或兼容分支。

## 验证

1. npm run check通过1504项测试，新增3项覆盖双方混合时间线、以上次显示时间为基准、分钟而非秒数间隔、重新渲染、新聊天、午夜和确认前后卡片样式。
2. 真实AI服务4271加载修改后的页面，复查既有真实模型合成对话。390×844下短回复宽220.33px，结构化已保存卡片宽304.67px，左侧头像均保留；1000×850宽屏复查正常。没有为已有成功对话重复请求模型，本次新增模型调用0次，启动时账本累计641次，上限仍为1000次、15元。
3. 固定时间合成页面单独验证时间左右和分钟边界，不加载模型，不能当作真实模型验收。用户16:40右对齐；卷卷16:42、16:44左对齐；16:43不输出时间元素。时间位于气泡外下方4px，头像只在卷卷一侧。
