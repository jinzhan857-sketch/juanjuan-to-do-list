## 实现与逐项核对

| 路径 | 日期归属与实际行为 |
| --- | --- |
| 设备、IP、全站 | 请求开始时北京时间日期；IP摘要也使用同一个日期，保持20、50与100上限，并按展随后明确要求增加全站每日100次；设备或IP拒绝不占全站预算 |
| 活跃 | 同一请求开始日，拒绝请求仍计活跃，重复设备去重 |
| calls | 同一开始日，进入模型调用前增加，限额拒绝不增加 |
| success | 模型解析成功后增加，跨午夜仍归开始日 |
| failures | 异常出口，包括Redis或模型失败，仍归开始日，不再按结束UTC日 |
| blocked | 超设备、IP或全站上限时增加，归开始日；不调用模型 |
| 查询 | 默认与非法日期回退请求开始日，有效历史日按明确日期读取 |
| 用户日期 | 四种模型角色保留有效用户日期，缺省与非法日期回退可信日，不用于计数 |
