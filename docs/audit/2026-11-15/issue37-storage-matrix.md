## 已执行矩阵

| 场景 | 预期 | 实际 |
| --- | --- | --- |
| 损坏 JSON、缺少集合、缺少 id、重复 id | 覆盖前拒绝，原资料不变 | 通过 |
| 非法日期、宠物、统计、图片、聊天或操作引用 | 整份拒绝，不过滤后继续导入 | 通过 |
| 同一文件重复覆盖 | 数量、附件、积分与宠物保持一致 | 通过 |
| 预览后取消 | 数据不变 | VM 中调用实际导入入口，通过 |
| 预览后资料变化 | 拒绝覆盖较新资料 | 通过 |
| 请求成功后事务 abort | Promise 拒绝，磁盘与内存不变 | 模拟库与原生浏览器均通过 |
| 批量第二条、操作记录、最终消息失败 | 整批回滚 | 通过 |
| 导入 kv 容量不足 | 旧库、内存与重开后的结果不变 | 注入 QuotaExceededError，通过 |
| 重复确认与直接并发执行 | 仅一份业务变更和操作记录 | 通过 |
| 撤销中断或撤销前内容变化 | 不覆盖较新资料，不留半批 | 通过 |
| 原生浏览器重开数据库 | 结果与提交状态一致 | 通过 |

重复编号采用整份拒绝，不静默去重或覆盖。这是 #6 结构校验的一部分，没有增加合并或兼容规则。图片与链接不截断后继续导入，非法或超出当前数量上限时给出原因。
