## 改动

底部保留并排两按钮，未识别可直接发布，识别成功只填充。分类可改，基础分只读；AI 分数沿用原尺度，识别后编辑不失效。新建失败自动规则评分并保存，编辑失败不自动写入。主动取消、换草稿、切换类型及离开表单使旧请求失效。服务异常、解析失败与追问分开，不无限重试。

本地评分移入[唯一模块](../../../src/rules/quick-score.mjs)，[评分文档](../../product/quick-scoring.md)先于实现整理。删除不再调用的旧关键词评分表，规则结果不进入模型缓存。模块原生 ES 加载，无环境兼容包装；构建复制模块，预览只开放确切模块 URL。生成短标题与应用文案通过独立 shortCopy 处理，用户资料不清洗。

两个发布入口共用 onSave、字段校验和 #6 的 commitDataChanges。草稿运行锁、固定身份和成功状态阻止重复写入；事务完成才更新内存。存储失败保留草稿及附件，成功但渲染失败明确已保存。编辑原记录不再通过旧的标题相等门槛，也不将标题调整引导为另建事务。已有结算公式和时间修改系数保留，已结算表单编辑的记录、统计差额与正向宠物奖励在同一事务提交。仅将原喂养算法增加显式宠物参数以准备写入快照，不改变食物和成长公式，不代表 #8 或 #28 整体完成。

## #43 独立结果

根因是 onAIClick 根据文本日期重设 missingDate，并直接覆盖表单日期，未保存用户选择来源。原保存门槛因此在有效日期下仍要求补选。本轮以 userFields 和请求前快照判断字段来源，无日期结果不抹除有效日期。

- [x] 时间表达没有日期时，手选日期、默认日期继续有效，直接持久化无需再点。
- [x] 请求中修改日期时间、标题备注及分类不被旧结果覆盖，冲突显示 AI 建议及保留日期。
- [x] 合成数据库核对跨月日期、具体时间和数量；电脑浏览器手选 11 月 20 日，输入“下午三点复习”，识别编辑后直接保存，数据库仍为 20 日。
- [ ] 真实手机同流程与跨月复验，尚未执行。

#47 明确默认今天有效，替代 #43 早期对未手选日期可能缺失的推测；非法日期仍阻止保存。

## 复验入口

npm run check 包含构建、文档链接、26 项稳定断言及 Node 测试。独立评分入口为 node --test scripts/quick-score.test.mjs；发布与数据库入口为 node --test scripts/publisher.test.cjs。本轮最终数量和 CI 以 PR 记录为准，最终本地完整回归为 208 项通过，包含识别成功但渲染失败不得自动发布的补测。新增业务测试只使用合成资料，固定版本 fake-indexeddb 验证事务，真实浏览器另行核对原生持久化。

node scripts/publisher-browser.cjs 提供 http://127.0.0.1:4176/ 隔离人工入口，模型模式可选成功、失败、追问及延迟；不会调用真实模型，正式 4173 资料不受影响。正式应用不能为验收改成模拟模型，此替身只存在于独立测试服务器。
