# 0004 产品主线与架构参考层级

日期：2026年11月15日。状态：展已确认产品主线和参考层级，授权记录具体借鉴方案；具体实现、依赖和新增任务范围待审核，本轮不实施。

## 决定与原因

卷卷以生活日程与待办的可靠记录为基础，AI辅助准确理解和处理事务为主要AI能力，再以相关记录、授权资料与实际反馈支持规划、聊天和提醒。产品定位在[产品说明](../product/README.md)维护，版本与入口在[版本定位与开源借鉴](../product/VERSION_POSITIONING.md)维护。

后续持续运行机制以Anthropic的[Building always-on agents](https://claude.com/resources/articles/building-always-on-agents)为主要架构参考，并参考其[简单性原则](https://www.anthropic.com/research/building-effective-agents)。nanoMuse保留局部实现、交互和测试参考，不作为整套基座。具体取舍与不采用理由统一在[借鉴方案](../reference/agent-learning-plan.md)维护，避免把产品案例、文章和开源代码当成同一类可直接接入的资源。

选择依据是卷卷的场景与维护成本，不因发布机构或项目热度直接证明效果。程序负责事实与确定性执行，模型负责理解、建议和必要判断；普通提醒不必调用模型。JavaScript与Python分工继续遵循[0002](0002-backend-language.md)、[0003](0003-javascript-python-boundary.md)，不因参考来源改变语言方向。
