## 5．当前数据与服务结构

### 浏览器数据

`DB.open` 位于 `index.html:1236`。数据库名为 `juanjuan-pet`，结构版本为 3。

| 对象仓库 | 内容 |
| --- | --- |
| `tasks` | 日程，含部分重复组字段、附件与计分结果 |
| `todos` | 无固定执行时间的待办 |
| `chats` | 会话元数据 |
| `messages` | 消息、确认卡与操作状态 |
| `memories` | 个人记忆 |
| `operations` | 助手执行与撤销快照 |
| `kv` | 宠物、逐日统计、自定义标签、记忆资料框等 |

内存镜像为全局 `S`。大模型配置、设备 ID、主题、草稿等另存于 localStorage。自定义 API Key 目前保存在浏览器 localStorage，未包含在应用 JSON 导出中。

浏览器数据按来源隔离。同一台电脑的本地预览与线上域名不自动共享数据，桌面和手机也不会因为打开同一个网址就自动同步。项目目录中的备份文件也不等于浏览器里当前所有数据。

页面启动会执行初始化、记忆框规范化和宠物跨日结算，因此打开应用并非严格无副作用。本轮没有手动创建、确认、删除、导入或重置业务数据。

### AI 服务

当前已有后端接口代码，但它尚不是独立、完整的业务后端。`api/ai.js` 使用 CommonJS 与 Node 内置模块，依赖 `req`、`res.status().json()` 等宿主接口，没有独立服务启动程序。

它负责评分或角色模型调用、结果清洗、请求限额与统计，业务数据的最终写入仍在浏览器。Redis REST 用于限额和运营计数，不是当前日程与记忆的云端业务数据库。

服务端使用的环境变量名称为：`DEEPSEEK_API_KEY`、`KV_REST_API_URL`、`KV_REST_API_TOKEN`、`RATE_LIMIT_SALT`、`OWNER_STATS_TOKEN`。本轮没有读取其值。

前端另有一套自定义模型提示词和结果清洗逻辑，存在与服务端重复维护的风险。当前没有统一的模型、动作、数据字段合同文件。
