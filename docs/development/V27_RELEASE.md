# V2.7 云端 AI 试用与发布

本分支界面和工程版本为2.7.0。展已确认长回复实测满意，随后追加记忆导入与首次引导。本轮仍先交展测试这两项，正式Pages保持V2.6，未发布V2.7。验收证据与保留失败见[本轮记录](../audit/2026-11-16/v27-cloud-preparation.md)，任务为[#82](https://github.com/jinzhan857-sketch/juanjuan-to-do-list/issues/82)，实施PR为[#146](https://github.com/jinzhan857-sketch/juanjuan-to-do-list/pull/146)。总计划未修改。

## 使用入口

[V2.7云端试用](https://juanjuan-v27-ai.vercel.app/)无需填写模型Key，也不依赖本机服务。免费公共次数为每设备每天300次、每周300次，全站公共池每周1000次；日额度在北京时间零点恢复，周额度在周一零点恢复，不按IP限制。失败与取消退业务次数，供应商可能已发生的费用不会因此退回。所有访客均可用，模型和联网工具会收费，Vercel与Upstash使用免费档。

云端支持聊天、规划、事务理解与评分、搜索、公开网页正文及已读资料续问。云端暂不支持图片，会明确提示。既有附件和用户自配能力保留，不增加图片存储服务。长回复完整保留；输出达到上限时明确提示分段，不再把600字符后的内容静默裁掉。

首页“今日完成”只显示短标签，三张统计卡等宽。首次真正空白的本机资料初始化时添加2条日程、3条待办；它们是普通记录，可以修改、完成、获得正常结算和删除。已有记录或已初始化资料不添加，刷新、清空这些示例后也不重新添加。欢迎日程当天全天，早睡日程为当天23:00至次日00:00。

第三个聊天推荐为“把其他 AI 的记忆带给卷卷”。点击后可复制整理提示词，到常用AI取得个人总结，再粘回聊天。卷卷分类形成候选，用户点“核对记忆”后在现有资料库中修改、删除或确认保存。未经确认不写入个人记忆；是否允许后续回答参考仍由原有开关控制。没有自动登录或读取其他AI账号。

设备绑定累计额度卡、人工发卡和重绑见[体验卡说明](V27_EXPERIENCE.md)。专属卡按累计余额使用，不按周恢复；公共额度与卡余额都不改变本轮真实测试预算。输入上限5000字；首页第三栏为未读提醒，点击查看并标为已读，模式选择已移除，图片入口改为加号，云端图片仍暂不支持。

## 数据与配置

日程、待办、聊天、记忆、宠物和积分仍在当前浏览器，备份格式仍为2.2，没有账户与跨设备同步。试用网址与原Pages网址属于不同来源，各自存储；不要清空原资料来试用。无痕窗口可查看首次引导。

前端固定请求 `https://juanjuan-v27-ai.vercel.app/api/ai`。Vercel项目为 `juanjuan-v27-ai`，区域hkg1；Upstash免费库 `juanjuan-v27-quota` 位于新加坡。服务配置名称为 `DEEPSEEK_API_KEY`、`KV_REST_API_URL`、`KV_REST_API_TOKEN`、`OWNER_STATS_TOKEN`、`AI_ENABLED`、`AI_ALLOWED_ORIGINS`、`AI_SOURCE_COMMIT`，不在仓库记录值。

指定放行来源包括原Pages、试用站和本轮合成验收来源4297。CORS是浏览器来源限制，不是用户身份验证。模型地址固定为DeepSeek官方接口，不接受客户端提供任意代理地址。生产请求最大1MiB；服务总截止45秒，浏览器等待50秒，额度预占60秒。

## 构建与部署

使用干净的已提交任务分支，先运行 `npm run check`、`npm run check:archive`，检查CI。真实模型验收必须继续使用本轮累计账本，不能新开默认额度或重置；本轮上限200次、1元，两项同时生效。配置检查 `npm run ai:live-check` 不调用模型。

运行 `npm run build` 后执行 `node scripts/v27-package.cjs`，只生成15个白名单部署文件，不上传仓库根目录、私有资料或环境文件。然后用官方Vercel CLI部署 `.reports/v27/deploy`，并将 `AI_SOURCE_COMMIT` 设置为同一完整提交。核对公开健康接口、build-info、页面及模块哈希，不仅看控制台显示部署成功。

展完成新增功能验收后，按[发布流程](RELEASE.md)合入并手动运行main的Pages工作流。正式入口仍为 [原Pages网址](https://jinzhan857-sketch.github.io/juanjuan-to-do-list/)，无需搬动该来源的浏览器资料。发布后还需核对正式来源、版本与跨域真实链路，不能以试用站代替正式发布证据。

## 停用与恢复

停止新请求时，将服务环境变量 `AI_ENABLED` 改为0并重新部署同一白名单包，核对健康接口enabled=false、普通请求拒绝以及取消退次仍可用。不要清Redis额度键、用户数据库或测试账本来恢复服务。

页面恢复依据为已发布V2.6提交 `5ffbce401f033ce5fd4562635ae518f1badb47ab` 和Pages运行43873698704。按现有main回退与手动发布流程重新检查后部署；云端停用与页面回退分开处理。出现密钥泄漏、越范围写入、资料损坏、限额可绕过或关键回归，停止对应收费与发布并保留证据。
