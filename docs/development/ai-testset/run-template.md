# 测试执行与问题记录模板

此文件是空白模板，没有实际回答或通过结论。用例定义见[cases.md](cases.md)，执行方法见[说明](README.md)。每轮复制为独立记录，不覆盖旧结果。

## 本轮信息

| 字段 | 填写内容 |
| --- | --- |
| 轮次及状态 | 例如日用广测第1轮，未执行/进行中/已停止/已完成 |
| 用例与场景版本 | 测试集版本、修改提交、题号范围、场景ID |
| 应用版本 | 源码提交、网页来源及构建信息；线上与本地分别填 |
| 测试时钟 | 固定时区、具体当前时间、特殊题使用的时钟 |
| 设备与来源 | 浏览器/手机实机/VM；独立来源、数据库或资料目录 |
| 模型路径 | 托管/自定义/免费模拟/保存回答回放；不要合并计通过 |
| 模型与指令 | 供应商、请求模型名、供应商报告名、提示词及解析器版本或哈希 |
| 工具与存储 | 模型、天气、Redis、数据库哪些是真实、哪些是替身 |
| 授权 | 展确认的范围、最多尝试次数、总费用预算；已有历史消耗 |
| 用量 | 每次请求Token、耗时、失败次数、保守估算及账单是否核对 |

## 每次尝试单独填一行

| 尝试ID | 题号/变体 | 路径/角色 | 输入与准备 | 实际最终回答链接 | 字段与最终状态证据 | 判定 | 用量/耗时 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 待填 | 待填 | 待填 | 待填 | 未执行 | 未执行 | 未执行 | 未执行 |

不得只保留成功的最后一次。模型原始最终回答、解析后对象、确认卡、确认前后数据库、刷新后结果、撤销后结果分别记录；不记录密钥或隐藏思考过程。题中只要求查询时，附命中编号与计数；没有写入要求时，附零写入和无关对象未变证据。

## 单个问题的证据卡

1. 简短问题：在什么入口、什么条件下发生什么错误。
2. 关联题：第一轮题号、第二轮变体号及正反例。
3. 复现：最少操作、最少合成资料、固定配置与时钟。
4. 预期与实际：保留模型最终回答及程序最终状态，不只贴报错或截图。
5. 频率：失败次数/尝试次数；不同配置分开统计，样本不足明确写。
6. 影响：回复质量、错字段、漏查询、误写、数据丢失、越权、费用或积分等。
7. 发生层：输入/角色选择/上下文/模型/清洗映射/校验确认/存储/工具网络/额度/显示；可先写未知。
8. 原因：确定事实、假设、反证、未排除条件分别写，不能拿推测充当已定位。
9. 关联Issue：先查已有任务；新增、补充、回归或需求待明确。
10. 验收：原失败、邻近正反例、最终状态、无关记录及回归范围。

## 本轮总结

- 已执行题数、实际请求次数和通过/失败/阻塞/待明确/未执行数量分别统计。
- 按共同原因归并的问题数，与失败题数分开；一个问题可以关联多个题。
- 已确认问题、待复现异常和新增需求分开，不把三者都写成已确认Bug。
- 给出已完成证据、停止原因、剩余预算、下一批测试建议和总计划入口。
- 已确认的写入、泄露或重复奖励风险不被整体平均通过率掩盖。
