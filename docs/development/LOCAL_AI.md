## 第一部分：现在就能运行，不需要Key

在任务的干净工作区执行：

```powershell
npm ci --ignore-scripts
npm run ai:dev
```

默认地址是 <http://127.0.0.1:4177/api/health>，用Ctrl+C停止。4173仍是原静态预览，两者分别运行；本入口不提供网页、仓库文件或.env，不接入真实浏览器资料。端口占用时保留原进程，可通过AI_LOCAL_PORT指定空闲端口，0表示自动分配，查看终端输出的实际地址。

此命令不加载.env，模型和额度均为合成模拟，不访问外部服务。模拟模型返回固定评分或固定聊天回复，不负责真实自然语言理解；处理函数使用的模拟时钟固定为2026年11月15日12:00，额度替身过期由实际经过的时间计算。每次重启清空模拟计数；它不是Redis，不证明真实持久化、故障恢复或公共额度已经验收。

免费自动测试命令：

```powershell
npm run ai:test
```

测试通过HTTP调用现有api/ai.js的真实处理及解析逻辑，模型和额度网络依赖使用测试替身，包含三种助手角色、识别、输入错误、次数上限、管理口令、服务错误和文件访问边界。测试中所谓真实连接入口加载验证使用合成处理函数，不访问真实模型。现有业务保存、确认和撤销仍由原回归覆盖，不将模拟聊天结果当作真实事务执行通过。

手工发送一条合成请求也可交给Codex执行：

```powershell
$sample = @{ title = '合成测试：整理书桌'; device_id = 'syntheticdevice0123456789abcd'; client_date = '2026-11-15' } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:4177/api/ai -ContentType 'application/json' -Body ([System.Text.Encoding]::UTF8.GetBytes($sample))
```

返回头X-Juanjuan-AI-Mode为simulation表示模拟，不以结果中的source字段单独判断是否真实调用。每条完成请求只记录请求编号、运行模式、状态码、耗时与处理函数SHA256，不记录输入、回复、Key、口令或存储地址。现有设备20次和IP50次规则继续由原处理函数运行，本任务不修改额度或计费规则。

## 第二部分：到这里等待人工

### 当前已确认与展只需做的一步

展已选择DeepSeek，同意本轮最多3次真实请求、不自动重试、预算1元；这只是本轮测试约定，后续可重新讨论放宽，不是产品永久限制。

本机根目录已准备私有.env，展只需在DEEPSEEK_API_KEY等号后填写自己的Key并保存，然后回复“已填好”。不要将Key发送到聊天。Codex只用程序检查是否填写，不打印文件或密钥值。

本轮采用真实DeepSeek加本地合成额度存储，因此不需要展申请或配置Redis。测试完整经过本机HTTP入口、原handler、真实模型和原解析器，额度仍标明合成模拟。它不验证真实Redis、云端全站额度或浏览器写入；这与后续完整真实服务配置分开。

填写后由Codex先运行npm run ai:live-check，只检查配置、不调用模型。再按已经确认的范围运行npm run ai:live-test，依次检查评分、创建日程建议和普通聊天，任一失败立即停止，没有自动重试，不执行模型提出的事务。规划模式本轮不增加真实调用，保留模拟覆盖。

执行器在发送前记录本轮尝试次数和保守金额预留，最多3次；网络失败也保留预留，不因重启或重跑自动恢复次数。账本保存在被忽略的.reports/issue81-live-budget.json，互斥文件阻止并发启动同一会话。结果已记录或次数已用尽时，须由Codex先复查，再经展授权开启后续测试，不删除记录来绕过上限。

金额按[DeepSeek官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)的Flash高峰价格估算：每百万输入2元、输出8元，使用输入字节数加安全余量及请求输出上限做预留；得到实际Token用量后另记高峰价估算。此为保守预算门槛，不是供应商账单硬封顶，也不是实际扣款。请求数不超过3次是本轮程序约束。没有真实Key前，不运行收费测试。

### 原完整真实服务的确认清单

Codex先给展以下清单，并等待完成，不自行选择收费资源或使用发现的其他Key：

1. 确认供应商和模型。本入口目前复用api/ai.js中的DeepSeek地址与模型配置，不接受客户端提交任意模型地址；更换供应商需要先明确范围。
2. 确认本轮真实请求数量、是否允许重试、输入输出限制与费用上限。现有规则是程序不自动重试，人工重试另计；预算不明确则停止真实调用。
3. Codex说明真实额度存储的接入方式及费用。现有处理函数需要Redis REST地址和令牌；第一部分模拟配置不能当作真实配置沿用，也不能为省配置静默跳过计数。
4. 确认后，由Codex准备本机私有配置文件和必要的随机口令，再让展安全填写供应商Key及适用的存储凭据。只提交.env.example中的变量名与空值，真实.env不入库。

需要的变量名称为DEEPSEEK_API_KEY、KV_REST_API_URL、KV_REST_API_TOKEN、RATE_LIMIT_SALT、OWNER_STATS_TOKEN；端口可通过AI_LOCAL_PORT设置。Key与随机口令不可复用，不在报告或聊天回显，检查时仅报告是否已填写。仅添加.gitignore不能保护已经被Git跟踪过的密钥文件，开工时须核对跟踪状态；密钥曾公开时须先更换。

## 第三部分：人工完成并授权后再运行

```powershell
npm run ai:serve
```

这个完整真实入口会加载工作区根目录.env，并复用现有api/ai.js，需要真实模型及真实Redis配置；当前尚未运行。另一条显式ai:live-test命令只测试真实模型，额度为合成模拟。已有进程环境变量优先于.env，修改后需重启。它们只绑定127.0.0.1，不开放公网、不配置跨域放行。请用Codex的本机HTTP测试调用，不直接把4173网页指向此跨端口服务；本任务没有改网页路由。

先GET /api/health，检查mode为live，ready为true。missing和invalid只列配置名称，不返回值。配置齐全只证明已填写，健康检查不发网络请求，也不证明余额、模型、Redis或网络有效。未配齐时POST返回503且不调用处理函数；只有后续POST才可能产生费用。

在已确认的调用次数和预算内记录合成输入、期望与实际、模型及提示词版本、源码、实际用量和耗时。现有接口未向本地日志返回供应商Token用量，真实阶段需要明确用量证据来源，不能用请求次数猜费用。通过后再核对必要的业务最终状态，补真实验收报告；未完成前不关闭#81。

## 与其他任务的边界

本入口与模拟不改index.html或api/ai.js，不重做[#29](https://github.com/jinzhan857-sketch/juanjuan-to-do-list/issues/29)可信日期或[#38](https://github.com/jinzhan857-sketch/juanjuan-to-do-list/issues/38)失败退款。模型与Redis只是假替身，未来原处理函数增加新的存储命令时，模拟会明确失败，应随新合同更新合成测试，不能静默放行。原业务、积分、宠物与数据库规则继续由原测试验证。

停止服务只停止本机入口，不修改或清空浏览器数据库。无需回退正式网站。需要新增云资源、改变模型或额度、暴露接口、迁移资料时，回到对应任务先讨论。
