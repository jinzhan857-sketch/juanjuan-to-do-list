## 第一部分：现在就能运行，不需要Key

在任务的干净工作区执行：

```powershell
npm ci --ignore-scripts
npm run ai:dev
```

默认地址是 <http://127.0.0.1:4177/api/health>，用Ctrl+C停止。4173仍是原静态预览，两者分别运行；本入口不提供网页、仓库文件或.env，不接入真实浏览器资料。端口占用时保留原进程，可通过AI_LOCAL_PORT指定空闲端口，0表示自动分配，查看终端输出的实际地址。

此命令不加载.env，模型和额度均为合成模拟，不访问外部服务。模拟模型返回固定评分或固定聊天回复，不负责真实自然语言理解；处理函数使用的模拟时钟固定为2026年11月15日12:00，额度替身过期由实际经过的时间计算。每次重启清空模拟计数；它不是Redis，不证明真实持久化、故障恢复或公共额度已经验收。

免费自动测试命令：

```powershell
npm run ai:test
```

测试通过HTTP调用现有api/ai.js的真实处理及解析逻辑，模型和额度网络依赖使用测试替身，包含三种助手角色、识别、输入错误、次数上限、管理口令、服务错误和文件访问边界。测试中所谓真实连接入口加载验证使用合成处理函数，不访问真实模型。现有业务保存、确认和撤销仍由原回归覆盖，不将模拟聊天结果当作真实事务执行通过。

手工发送一条合成请求也可交给Codex执行：

```powershell
$sample = @{ title = '合成测试：整理书桌'; device_id = 'syntheticdevice0123456789abcd'; request_id = [guid]::NewGuid().ToString('N'); client_date = '2026-11-15' } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:4177/api/ai -ContentType 'application/json' -Body ([System.Text.Encoding]::UTF8.GetBytes($sample))
```

返回头X-Juanjuan-AI-Mode为simulation表示模拟，不以结果中的source字段单独判断是否真实调用。每条完成请求只记录请求编号、运行模式、状态码、耗时与处理函数SHA256，不记录输入、回复、Key、口令或存储地址。最新#38接口要求每次新请求显式提供32位小写十六进制request_id，重试需新编号，取消用原编号；本机服务不为缺失编号补值。客户端真实测试入口自动为自己的请求生成编号，模拟额度通过#38共用的quotaOracle替身实现，不执行真实Redis Lua，不验证Redis租约与原子性。设备20次、IP50次及全站100次规则沿用原处理函数，本任务不修改额度或计费规则。

### 后续聊天怎样继续使用

同一台电脑、同一Windows账户下，卷卷的新聊天、新工作区统一复用用户目录下.config/juanjuan/ai.env。Windows位置为%USERPROFILE%\.config\juanjuan\ai.env，位于仓库和所有工作区之外，已限制当前Windows用户与SYSTEM访问。仅其中的DEEPSEEK_API_KEY共享；Redis和管理口令等服务配置仍留在对应工作区。

scripts/ai-config.cjs由显式真实入口加载。非空配置优先级为进程环境、工作区.env、用户目录共享文件。空的.env示例Key不会挡住共享Key。需要更换共享Key时只改用户目录文件，随后重新启动相关进程。免费ai:dev和离线ai:test不读取真实私有配置。

先运行npm run ai:live-check，key_configured为true且key_source为machine，表示已经自动读取共享配置，没有发送模型请求。已用两个不含.env的新目录和新Node进程完成检查，不复制密钥到新目录。

本机Codex全局AGENTS.md已补充仅针对卷卷仓库的接手规则，新聊天先核对项目再复用配置。分支尚无共享读取入口时，PowerShell可用Node原生参数node --env-file="$env:USERPROFILE\.config\juanjuan\ai.env" <现有入口脚本>向单次进程传入，不把Key写进命令。已有聊天不会保证自动重新加载全局说明，接手时可直接阅读本页。不将私有文件复制进仓库，也不修改Windows全局环境变量。

共享的是Key，不是测试授权或免费额度。各工作区的测试账本仍在各自.reports，接手者须先核对当轮共识与已有调用，不能换工作区后清零重复使用预算。真实调用需要网络可用和供应商账户有余额，本轮10次、2元不是永久预算，且当前次数已经用满。换电脑或换Windows账户仍需安全配置。当前本机接口只绑定127.0.0.1，公网共享由#82另行讨论。

### 原完整真实服务的确认清单

Codex先给展以下清单，并等待完成，不自行选择收费资源或使用发现的其他Key：

1. 确认供应商和模型。本入口目前复用api/ai.js中的DeepSeek地址与模型配置，不接受客户端提交任意模型地址；更换供应商需要先明确范围。
2. 确认本轮真实请求数量、是否允许重试、输入输出限制与费用上限。现有规则是程序不自动重试，人工重试另计；预算不明确则停止真实调用。
3. Codex说明真实额度存储的接入方式及费用。现有处理函数需要Redis REST地址和令牌；第一部分模拟配置不能当作真实配置沿用，也不能为省配置静默跳过计数。
4. 确认后，由Codex准备工作区私有服务配置和必要的随机口令；本机已有的共享模型Key直接复用，只在缺少适用存储凭据时让展安全填写。只提交.env.example中的变量名与空值，真实.env及共享ai.env不入库。

需要的变量名称为DEEPSEEK_API_KEY、KV_REST_API_URL、KV_REST_API_TOKEN、RATE_LIMIT_SALT、OWNER_STATS_TOKEN；端口可通过AI_LOCAL_PORT设置。Key与随机口令不可复用，不在报告或聊天回显，检查时仅报告是否已填写。仅添加.gitignore不能保护已经被Git跟踪过的密钥文件，开工时须核对跟踪状态；密钥曾公开时须先更换。

## 第三部分：人工完成并授权后再运行

```powershell
npm run ai:serve
```

这个完整真实入口会加载工作区服务配置并读取共享模型Key，复用现有api/ai.js，需要真实模型及真实Redis配置；当前尚未运行。另一条显式ai:live-test命令只测试真实模型，额度为合成模拟。非空进程环境变量优先于工作区.env及共享Key，修改后需重启。它们只绑定127.0.0.1，不开放公网、不配置跨域放行。请用Codex的本机HTTP测试调用，不直接把4173网页指向此跨端口服务；本任务没有改网页路由。

先GET /api/health，检查mode为live，ready为true。missing和invalid只列配置名称，不返回值。配置齐全只证明已填写，健康检查不发网络请求，也不证明余额、模型、Redis或网络有效。未配齐时POST返回503且不调用处理函数；只有后续POST才可能产生费用。

在已确认的调用次数和预算内记录合成输入、期望与实际、模型及提示词版本、源码、实际用量和耗时。现有接口未向本地日志返回供应商Token用量，真实阶段需要明确用量证据来源，不能用请求次数猜费用。通过后再核对必要的业务最终状态，补真实验收报告；未完成前不关闭#81。

## 与其他任务的边界

本入口与模拟不改index.html，api/ai.js仅在真实测试排错时加入显式关闭思考的设置，以及收尾明确聊天需转事务模式的既有提示词边界，不重做[#29](https://github.com/jinzhan857-sketch/juanjuan-to-do-list/issues/29)可信日期或[#38](https://github.com/jinzhan857-sketch/juanjuan-to-do-list/issues/38)失败退款。已整合其他聊天完成的日期、额度与草稿修复，保留其成果。免费模拟中的模型与Redis均为替身；显式真实模型测试仅替换模型传输，Redis仍为替身。未来原处理函数增加新的存储命令时，模拟会明确失败，应随新合同更新合成测试，不能静默放行。原业务、积分、宠物与数据库规则继续由原测试验证。

停止服务只停止本机入口，不修改或清空浏览器数据库。无需回退正式网站。需要新增云资源、改变模型或额度、暴露接口、迁移资料时，回到对应任务先讨论。
