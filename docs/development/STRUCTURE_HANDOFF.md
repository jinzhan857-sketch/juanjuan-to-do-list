## 结构整理边界

这是对#9既有职责的细化，不改变已确认产品规则、数据格式、积分、宠物或3.0范围，不授权现在改代码。目标是减少改动牵连和定位成本，不追求前后端占比、文件数量或框架名称。

| 职责 | 目标边界 | 可核对的结果 |
| --- | --- | --- |
| 确定性规则与合同 | 明确输入和输出，环境无关部分不读DOM、数据库、网络或可变全局状态 | 测试直接调用实际模块；表单与助手复用需要一致的校验与编辑公式 |
| 状态与持久保存 | 明确谁持有状态、谁可提交写入；事务完成后再发布内存变化 | 操作、撤销、导入的正常与失败结果一致；界面不直接拼跨存储事务 |
| 业务执行 | 核对目标、范围、快照及重复操作，组合业务变化并提交 | 表单和助手走明确入口，界面不复制执行算法，执行层不刷新页面 |
| AI与工具适配 | 分开网络、取消、天气、上下文、协议、提示词来源 | 托管与自定义有共同语义契约及各自必要校验；不影响已有额度、退次、隐私和取消 |
| 视图与启动 | 接收状态或业务结果，渲染、收集输入、绑定事件 | 启动不执行测试样本，视图可在不执行真实业务写入时验证 |
| 测试与构建 | 测试加载真实模块，产物只含明确需要的运行文件 | 源码预览、构建预览、干净下载与无Git归档都能加载；私人文件与测试夹具不进入公开产物 |

用少量明确模块实现即可。准确目录、接口名称与拆分顺序由每批实施前结合最新main确定并写进#9；本页不冻结一套空目录或新增框架，不要求先建完整状态管理、事件总线、微服务或配置平台。

同一规则的源码应只有一份。前端可以为输入体验做校验，服务端仍须独立核对收到的数据；不得把“只维护一份规则”误读为“信任前端结果”。环境适配不复制算法，不新增兼容包装。

## 多个聊天怎样配合

1. 接手先读根目录AGENTS.md、README.md、[STATUS](../STATUS.md)、[当前架构](../architecture/README.md)、[数据](../architecture/DATA.md)、[AI](../architecture/AI.md)、[开发](README.md)、[测试](TESTING.md)、[发布](RELEASE.md)，再读#1、本页和目标Issue。核对最新main、正式站点来源、工作区及已开启PR；旧目录不能因为能打开就当作最新代码。
2. 获得具体批次授权后，在#9、#124或#123对应任务登记负责的批次、基准提交、拟改文件、接口和验收范围；#106完成记录保留，不重复派工。只是阅读或准备资料不占用实现批次。不要发送其他聊天消息或打断在做任务，协作信息保存在Issue和PR中。
3. 同一时间由一个实现者整合index.html、package.json、构建脚本和公共测试夹具。其他聊天可独立审查、准备合成场景或在已经稳定的模块边界开发；确需修改共享文件时，先在Issue说明拆分边界并等待上一批合入，不各自搬动同一段代码。
4. 复用合适且干净的现有工作区，使用codex分支；原目录有来源不明或其他聊天的未提交改动就保留，不能重置、清理或顺带提交。PR只包含本批相关源码、测试与必要说明。
5. 每批先记录最小方案、输入输出、当前真实调用者与行为基线，再实施。发现实际结构需重大调整、需要兼容、改产品规则或明显增加维护成本时，先向展说明具体变更并确认；既有授权内的小批拆分不重复索要许可。
6. 每批验收并合入后，更新#9原清单及实际成果链接，更新当前架构的真实模块位置和STATUS接手结论；下一批基于新main继续。提取了文件、测试通过或文档补齐均不能单独宣称整个架构整理完成。

## 每批验证和停止条件

基线与完成检查使用同一合成场景、固定时钟和已说明的来源。相关规则、存储、业务与隔离浏览器必须核对最终记录、目标条数、无关资料、附件、积分及宠物；保留正常、取消、重复确认、失败、撤销和重开场景。历史Bug以已确认正确规则判断，不把错误行为冻结为必须保持。

执行相关专项、npm run check及必要的npm run check:archive；改动发布入口或模块加载时检查源码与产物两种预览、允许的HTTP路径和实际导入。测试从单页提取迁到模块时保留旧用例对应关系，不能只靠重写测试让绿灯恢复。必要的集成测试可以继续加载页面，纯规则和业务模块不应为测试被迫启动整页应用。

每批更新依赖表，检查规则层不反向依赖视图、运行模块不导入测试、无新增循环依赖；用实际导入和关键负向场景证明边界。选择轻量可维护检查，不强制为了检查引入新依赖或复杂框架，不以文件长度作为唯一验收。

出现越范围写入、内容丢失、重复奖励、初始化退步、无关资料变化、关键测试退步或无法恢复，停止本批并保留复现。仅回退本批代码，不清理用户数据库或覆盖其他聊天成果；无法证明行为一致时不合入。发布、迁移和真实模型调用仍分别授权，失败记录与未测设备保留。
